# Когда пользователь мед сервиса — ИИ-агент

Когда пользователь мед сервиса — ИИ-агент — Пример ИИ-агента для медицинского сервиса, который предоставляет рекомендации и позволяет пользователям оставлять обратную связь.

Рабочий пример кода к статье канала.
