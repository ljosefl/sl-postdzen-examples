# Встречаются случайные `console.log()` в `stdout`

Встречаются случайные `console.log()` в `stdout` — Программа для проверки MCP-серверов на наличие случайных `console.log()`, отсутствие аннотаций `destructiveHint` и вшивание промптов.

Рабочий пример кода к статье канала.

## Файлы

- `main.ts`
- `package.json`
- `tsconfig.json`
- `test.ts`
- `requirements.txt`

## Запуск

```
python main.ts
```
