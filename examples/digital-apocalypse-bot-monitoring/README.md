# Каждый третий пост про цифровой апокалипсис в интернете написал ИИ-бот

Каждый третий пост про цифровой апокалипсис в интернете написал ИИ-бот — Пример кода для мониторинга и анализа постов в интернете, чтобы определить, сколько из них создано ИИ-ботами.

Рабочий пример кода к статье канала.

## Файлы

- `main.py`
- `requirements.txt`
