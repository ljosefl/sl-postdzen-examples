# Астроном-любитель с ИИ-агентом анализируют данные телескопа Евклид

Астроном-любитель с ИИ-агентом анализируют данные телескопа Евклид — Пример программы для анализа данных телескопа Евклид в формате FITS с использованием библиотеки astropy и предварительной обработкой данных ИИ.

Рабочий пример кода к статье канала.

## Файлы

- `main.py`
- `requirements.txt`

## Запуск

```
python main.py
```
